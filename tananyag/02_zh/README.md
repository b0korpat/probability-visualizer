# 02. ZH - az elküldött órai anyag levezetései

Ez a mappa a most elküldött öt képet tartalmazza. Az első két kép ugyanahhoz a pálcatöréses feladathoz tartozik.

## A 2. ZH témái

1. Pálcatörés: geometriai és feltételes valószínűség, függetlenség
2. Három egymást követő esemény: szorzási szabály és feltételes valószínűség
3. Gyári selejt: teljes valószínűség és Bayes-formula
4. Fiúk és lányok: eseménytér, feltételes valószínűség, függetlenség három- és négygyerekes családoknál

Az oldalon mindegyik feladat a küldött megoldások logikájával, lépésenként levezetve jelenik meg.
